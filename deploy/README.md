# Deploy Directory

`deploy/` is the production deployment surface. Treat
`deploy/docker-compose.yml` and `deploy/.env.example` as the deploy contract;
`docker/` only contains Dockerfiles and the local development compose file.

Current Docker development, release, deploy, data-directory, and troubleshooting
instructions live in:

- [OpenAgents Docker 开发与发版流程](../docs/guides/docker-compose-prod-selfhost-zh.md)

Runtime files generated by `scripts/docker-deploy.sh` are ignored by git:

- `.env`
- `config.yaml`
- `gateway.yaml`
- `migrations/`
- `data/`
